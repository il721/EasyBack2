# Available Tools

Below is a list of tools available for use during this session:

### File Management & Code Editing
- **`create`**: Create a new file with specified content.
- **`search_replace`**: Apply a single search-and-replace operation to a file.
- **`multi_edit`**: Apply multiple search-and-replace operations to a single file in one go.
- **`rename_element`**: Rename symbols (classes, functions, etc.) and update all references across the project.
- **`undo_edit`**: Revert the last edit made to the project.
- **`lint`**: Analyze a file for syntax errors, semantic errors, and warnings.

### Project Navigation & Analysis
- **`get_file_structure`**: Display the code structure (classes, methods, imports) of a file.
- **`search_project`**: Search for file names, symbols, or text strings within the project.
- **`open`**: View 100 lines of a file starting from a specific line number.
- **`open_entire_file`**: Open the entire content of a file.
- **`scroll_down` / `scroll_up`**: Move the view window up or down in an open file.

### Terminal & Environment
- **`bash`**: Execute standard PowerShell commands in the terminal.

### Information Gathering & Communication
- **`web_search`**: Search the web for up-to-date information, documentation, or technical solutions.
- **`fetch_url`**: Retrieve and extract content from a specific URL.
- **`ask_user`**: Ask the user for help or clarification.

### Workflow & Submission
- **`update_status`**: Update the status and plan of the current task (used in `[CODE]` mode).
- **`submit`**: Submit the solution and terminate the session.
- **`answer`**: Provide a comprehensive answer to the user and terminate the session.
